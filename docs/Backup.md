# System Backup Automation (Management Inventaris)

The backup system runs automatically every 5 hours, using Python programming language technology combined with the Java programming language to provide an auto backup schedule

## Technologies Used

- **Python**: I use Python to carry out the backup process with quite good performance, and take all the data in the database into the ./backup folder
- **Java**: I use Java to schedule an auto backup system every 5 hours, so that developers don't have to run backups manually continuously
- **Gpg**: I use Gpg to encrypt SQL data into .gpg which can later be decrypted using gpg too and using the decrypt password
